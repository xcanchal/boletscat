# Marca Boletada

- `boletada-app-icon-1024.png`: icona quadrada per RevenueCat i base per a les apps.
- `boletada-logo-1600x400.png`: logotip horitzontal transparent per RevenueCat.
- `boletada-og-1200x630.png`: imatge de previsualització per xarxes i missatgeria.
- `icon-192.png` · `icon-512.png`: icones del manifest PWA, reduïdes de
  `boletada-app-icon-1024.png`. El bolet queda dins de la zona segura del 80%,
  així que el mateix fitxer serveix com a `maskable`.
- Els fitxers SVG són les fonts editables dels mateixos assets.

Els cercles concèntrics només apareixen com a textura secundària a la icona i a
la imatge social. El logotip horitzontal queda net per mantenir-ne la llegibilitat.
